# DarkSurvive

**ホラー風デッキ構築型ローグライク。100階の塔を、カードだけを頼りに登りきれ。**

参考：Slay the Spire / クトゥルフと夢の階段　雰囲気：バイオハザードのようなサバイバルホラー

▶ **ブラウザで遊ぶ：** https://kikuchitakumi.github.io/darkSurviveSteam/
（main ブランチに push すると自動で更新されます）

---

## 遊び方
1. **START** → ステータスがランダムに決まる（1回だけ振り直し可。まれに「才能」が開花）
2. **1F** … 扉を開ける／帰る／周りを探索する（隠し通路→宝物庫）／祈る
3. **2F 以降** … 2つの扉から進む道を選ぶ（戦闘・戦闘(危険)・イベント・ショップ）
4. **10F ごと** にボス戦。**100F のラスボス** を倒せばクリア
5. 戦闘に勝つと G・経験値・カード（3枚から1枚）を獲得。レベルアップでステータスを強化

| 操作 | 内容 |
|---|---|
| カードをクリック / ドラッグ | 使う（敵を狙うカードは矢印で対象を選ぶ） |
| 1〜9, 0 キー | 手札のカードを選ぶ |
| E キー | ターン終了 |
| Esc / 右クリック | キャンセル・閉じる |
| Enter / Space / クリック | メッセージを進める |

## 仕様の解釈（仕様書に明記がなく、こちらで決めた点）
数値は全て [src/config/balance.ts](src/config/balance.ts) で変更できます。

| 項目 | 決めた内容 |
|---|---|
| 最大HP | **20 + 体力ステータス × 10**（体力の上限は99。初期値1〜5のままだと最大HPが1〜5になり戦闘が成立しないため） |
| 攻撃力 / 防御力 / 魔力 | 攻撃カードのダメージ / 防御カードのブロック / 魔法カード・回復量 に加算 |
| 運 | クリティカル率・回避率 = 運÷99×50%（最大50%）。イベントの運判定の成功率にも加算 |
| 才能 | 各ステータス 3% の確率で開花し、値が 8〜12 になる |
| 強敵（危険） | 同じ階の敵に対して HP 2倍・攻撃 1.5倍（＝総合的に約2倍の強さ） |
| 敵の強さ | 階が上がるごとに HP +9% / 攻撃 +6%（100F で HP 約10倍・攻撃 約7倍）。`npm run sim` のボット検証で調整 |
| 強敵の出現 | 5F 以降 |
| 封印 | 封じられた敵は次のターン「封印耐性」を得る（ハメ防止）。70F・100F のボスは無効 |
| 宝物庫 | 1F の探索に加え、鍵を持っていると 2F 以降でまれに「隠し通路」が出現 |
| 鍵の入手 | ショップで購入 / 強敵・ボスのドロップ |
| ボス撃破 | HP 全回復 |
| ステータスポイント | レベルアップ時に割り振り。「あとで」に回してステータス画面から振ることも可能 |
| カード報酬 | 仕様通り、現在は初期デッキの5種類のみ。闇商人だけが強力なカード（追加カードのサンプル10種）を販売 |
| イベント | 仕様通り「20Gもらう / HP20回復」の1種類のみ有効。追加用のテンプレートを2つ用意（`enabled:false`） |
| 背景画像の形式 | **WebP**（PNG だと1枚1.7MB → WebP で約35KB）。透過が必要な画像は PNG |

## 見た目の方向性
重厚なダークファンタジーのデジタルカードゲーム風（金属の装飾枠・宝石・金の浮き彫り）。
- カード：レア度ごとの金属枠（ブロンズ／シルバー／ゴールド／レジェンド）、マウスに合わせた3D傾きと光沢、レア以上はホログラム
- UI：ボタン・パネルは装飾枠の画像を9スライスで使用（どのサイズでも角が崩れない）
- 戦闘：主人公の肖像（リーダー枠）・APクリスタル・丸いターン終了ボタン・意図のメダリオン

## 画像・音について
- 現在の画像・効果音・BGM は **自動生成した仮素材** です（タイトルBGMのみカスタム曲）。画像の右下に用途とファイル名が小さく書いてあります。
- 本番のイラストは [docs/ART_PROMPTS.md](docs/ART_PROMPTS.md) のプロンプトで画像生成AIを使って作れます（`npm run art:prompts` で再生成）。
- `public/assets/` に **同じファイル名で上書き** すれば差し替わります。一覧は [docs/ASSETS.md](docs/ASSETS.md)。
- 仮素材の再生成：`npm run gen:images` / `npm run gen:audio`（既存ファイルは上書きしません）
